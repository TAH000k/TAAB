# TAAB

**TAAB** is a family book sharing platform.

A place where members can:
- Add their books
- Share books with others
- Request and reserve books
- Track book availability

## About

TAAB is designed to help a community of readers manage their personal libraries and share books easily.

## Features (v1)

- User accounts
- Book management
- Book cover images
- Book reservation system
- Borrowing status tracking
