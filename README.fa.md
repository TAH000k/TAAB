# TAAB (تاب)

یک پلتفرم متن‌باز برای مدیریت کالاهای اشتراکی و امانت گرفتن.

---

## معرفی

تاب (TAAB) یک پلتفرم امانت‌دهی متن‌باز است که به خانواده‌ها، دوستان، مدارس، گروه‌ها و سازمان‌ها کمک می‌کند تا کالاهای اشتراکی خود را مدیریت کرده و فعالیت‌های مربوط به امانت دادن و پس گرفتن را پیگیری کنند.

تمرکز این پروژه بر سادگی، شفافیت و مقیاس‌پذیری است و همزمان یک REST API تمیز و یکپارچه ساخته‌شده با FastAPI ارائه می‌دهد.

## ویژگی‌ها

### پیاده‌سازی شده

#### احراز هویت (Authentication)
- ثبت‌نام و ورود کاربر
- احراز هویت مبتنی بر توکن (JWT)
- جریان استاندارد OAuth2 با رمز عبور
- هش کردن رمزهای عبور با استفاده از bcrypt
- امکان به‌روزرسانی اطلاعات پروفایل

#### مدیریت کالاها (Item Management)
- ثبت کالای جدید
- مشاهده لیست کالاهای شخصی
- دسته‌بندی کالاها
- مدیریت وضعیت موجودی کالا
- نمایش وضعیت فعلی امانتِ کالا
- حذف نرم (Soft delete)
- آپلود تصویر برای کالاها
- جستجوی کالاها
- فیلتر کردن پیشرفته کالاها
- صفحه‌بندی (Pagination)

#### گروه‌ها و کنترل دسترسی (Groups & Access Control)
- ایجاد و مدیریت گروه‌های اختصاصی (مانند: "دوستان صمیمی")
- افزودن و حذف کاربران در گروه‌های خاص
- کنترل دسترسی و قابلیت مشاهده کالاها بر اساس گروه

#### سیستم امانت‌دهی (گردش کار TAAB)
- ثبت درخواست امانت
- مشاهده درخواست‌های ارسال‌شده
- مشاهده درخواست‌های دریافت‌شده
- تایید درخواست امانت
- رد درخواست امانت
- اعتبارسنجی منطقی مالکیتِ کالا هنگام امانت‌دهی
- تایید دوطرفه برای تحویل کالا (Handover)
- تایید دوطرفه برای بازگشت کالا (Return)
- لغو درخواست‌های در حال انتظار یا تایید شده
- مدیریت و حل‌وفصل اختلافات (Dispute Management)

#### اعلان‌ها (Notifications)
- نوتیفیکیشن خوش‌آمدگویی
- نوتیفیکیشن‌های مربوط به درخواست‌های امانت

#### تست نرم‌افزار (Testing)
- تست‌های خودکار جامع با استفاده از `pytest`
- پوشش کامل چرخه حیات برنامه و سناریوهای Edge-cases

## راه‌اندازی سریع

```bash
git clone https://github.com/TAH000k/TAAB.git

cd backend

python -m venv venv

# در ویندوز:
venv\Scripts\activate

# در مک / لینوکس:
source venv/bin/activate

pip install -r requirements.txt

alembic upgrade head

# اجرای سرور
uvicorn app.main:app --reload

# اجرای تست‌های خودکار
python -m pytest -v
```
